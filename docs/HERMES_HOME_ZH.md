# Hermes 多成员网关说明

这个版本把 Hermes 扩展成多成员网关形态，但不修改 Hermes 本体，方便后续继续升级 Hermes。

它可以用于家庭，也可以用于企业、小团队、工作室或其他组织。

## 核心设计

- `home-master` 是主网关，负责消息归总、共享记忆检索、统一生成回复。
- 每个成员使用一个独立从网关，例如 `wechat2`、`wechat3`。
- 每个从网关独立绑定一个微信账号，登录态和频道配置互不污染。
- 从网关通过 `home-slave-relay` 插件把消息转发给主网关。
- Web UI 负责创建从网关、自动分配端口、切换网关配置、改显示名、管理共享记忆。

## 新建网关

点击“新建网关”后：

- 自动 clone `home-master` profile。
- 自动清空频道配置和微信凭据。
- 自动分配下一个端口。
- 自动安装并启用 `home-slave-relay` 插件。
- 自动写入 `/opt/hermes-home/config.yaml`。
- 自动启动该网关。

从网关默认作为已登记成员入口，不再绑定旧 OpenID 白名单，避免出现“扫码成功但没反应”的问题。

## 微信首次绑定

新微信绑定成功后，第一次发消息会触发初始化询问。用户可以回复：

- `我是张三`
- `我叫小王`
- `叫我李经理`

系统会自动把该从网关显示名更新为对应成员名。也可以在 Web UI 网关页面手动点击“改名”。

## 共享记忆

共享记忆是长期共享记录，不混入个人聊天上下文。只有在问题需要历史、安排、成员关系或重要事件时才检索。

Web UI 支持：

- 搜索共享记忆
- 按重要度过滤
- 新增
- 编辑
- 删除

AI 自动保存时会按多维度判断，例如多人提及、共同决定、成就、大事件、健康、日程、长期偏好等。
